# 说话有谱｜比赛现场运行手册

## 当前冻结版本

- 当前冻结提交：`122e851`（情境必填、第二幕追问可跳过）
- 视觉安全修复提交：`80c87ac`
- 本地生产地址：`http://localhost:3001`
- 离线备用地址：同一地址；将 `COACH_MODE` 设为 `preset` 后重启即可

## 上台前准备

1. 在项目目录执行 `npm install`。
2. 确认 `.env.local` 已配置 `COACH_MODE=real`、`AI_API_KEY`、`AI_BASE_URL`、`AI_MODEL`。
3. 执行 `npm run typecheck`、`npm run test:coach-protocol`、`npm run build`。
4. 启动生产版：`npm start -- --port 3001`。
5. 浏览器提前打开 `http://localhost:3001`，完成一次场景 A 彩排。
6. 将浏览器缩放固定为 100%，准备稳定网络和电源。

## 推荐主演示：场景 A

1. 第一幕选择“领导”、男、强势。
2. 展开“演示模式：一键载入主演示场景”，点击“场景 A · 周末加班”。
3. 进入第二幕，确认沟通困境已预填。
4. 展示 AI 追问；回答或点击“跳过这个问题”。最多两轮。
5. 第三幕强调三张策略卡，以及翻面后的“对方可能反应”。

## 备用演示：场景 B

1. 返回第一幕，载入“场景 B · 客户延期”。
2. 展示“甲方/客户、女、多疑”对象设定。
3. 进入第三幕后翻开至少一张卡，突出客户的怀疑反应与可执行回应。

## 断网兜底

如果真实 AI 超时、断网或返回异常：

1. 等待页面进入“剧场暂时断线了”。
2. 点击“使用离线排演”。
3. 继续展示预设结果，不解释技术细节。

如果需要赛前直接使用离线模式，在 `.env.local` 设置 `COACH_MODE=preset`，重启 `npm start -- --port 3001`。离线模式不依赖网络。

## 现场表达重点

> 它不是只替你写一句话，而是先判断你在担心什么，再给出三种说法，并预演对方可能怎么回应。

演示顺序保持“困境 → 追问/跳过 → 三种策略 → 翻卡反应”，不要现场展开概念实验页或修改功能。

## 最后检查

- [ ] 第一幕、第二幕、第三幕的按钮完整可见。
- [ ] 场景 A 一键载入可用。
